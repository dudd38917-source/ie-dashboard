📋 各工作站閒置時間與稼動率明細表

計算公式說明：
1. 總閒置時間（全活動區間） = 活動總耗時 − 該站總加工時間 = 「開工前等料」＋「站內換件空檔」＋「收尾閒置」。
2. 站內換件空檔（件間等待） = 同一工站連續作業之間的停頓時間總和（下一件開工時間 − 上一件完工時間）。
3. 稼動率（Utilization） = 該站實際加工時間 ÷（實際加工時間 ＋ 總閒置時間）× 100%。
4. 每週期平衡閒置 = 瓶頸站平均 Cycle Time − 該站平均 Cycle Time。
